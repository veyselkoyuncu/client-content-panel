# Content Panel

Client and content tracking panel for agency account managers: manage clients, track their content (social media posts, blog posts, web pages and more) through draft, review and published states, and see the overall status on a dashboard.

The repository contains two independent applications, each with its own setup, documentation and deployment.

| App | Description | Docs |
|---|---|---|
| [`backend/`](backend) | REST API — Fastify, TypeScript, Kysely, PostgreSQL, Docker | [backend/README.md](backend/README.md) |
| [`frontend/`](frontend) | Web app — Next.js, TypeScript, Tailwind CSS | [frontend/README.md](frontend/README.md) |
